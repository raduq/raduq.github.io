# raduq.github.io

:)

Site estático publicado pelo GitHub Pages, sem build. A página inicial está em
`index.html`; os estilos compartilhados ficam em `css/home.css`, e o blog em
`posts/index.html` e `posts/0-hello-world/index.html` usa também `css/blog.css`.
O tema é compartilhado entre a home e o blog via `js/theme.js`; as interações
exclusivas da home (experiência e avatar) ficam em `js/home.js`.

Para visualizar localmente, execute `python3 -m http.server 8000` na raiz do
repositório e abra `http://localhost:8000/`.
